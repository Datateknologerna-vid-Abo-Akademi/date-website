# Curated page list for the CSS regression harness.
#
#   uv run python scripts/css_regression.py capture --label before \
#       --pages scripts/css_regression_pages.txt
#
# This set exists to give every shared and association stylesheet at least one
# page that loads it, so an appearance-neutral claim can actually be checked.
# The five seasonal event paths (/events/arsfest/, /events/baal/,
# /events/kk100/, /events/tomtejakt/, /events/wappmiddag/) only resolve when an
# event exists whose title or slug selects that template; the dynamic fixtures
# create one of each for exactly this reason.
#
# Some paths are only reachable when signed in. Captured without credentials they
# redirect to the sign-in page, and the harness would record that sign-in page as
# if it were the requested path. Capture them with
# CSS_REGRESSION_USERNAME and CSS_REGRESSION_PASSWORD set (or --username and
# --password); the login object in manifest.json then says the capture was
# authenticated. Those paths are marked below.
#
# Two of the listed paths also render live, time-dependent content, which changes
# between any two captures even when the stylesheet change is appearance-neutral:
# /members/cert/ paints a wall clock into #clock-wrapper and refreshes it every
# 500 ms, and an event page whose sign-up has closed renders a relative time such
# as "39 minuter sedan" into #no-registration. A capture intended to reach a green
# verdict therefore passes both masks:
#
#   uv run python scripts/css_regression.py capture --label after \
#       --pages scripts/css_regression_pages.txt \
#       --mask '#clock-wrapper' --mask '#no-registration'
#
# The mask sets visibility: hidden on just those elements (never display: none,
# which would remove them from layout and shift everything below them), so the
# rest of each page is still compared.
#
# One path per line. Blank lines are ignored and everything from a '#' to the
# end of the line is a comment. Every path must start with '/'.
